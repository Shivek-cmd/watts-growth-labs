## Design Notes

| Element | Watts Growth Labs design token used (from `index1.html` `:root`) | Applied here |
|---|---|---|
| Layout | 600px table-based card, MSO-safe, hidden preheader | Same structure as ET-01/ET-02 |
| Accent bar | `--bronze` `#a27e4b` | Single-tone bar, top and under-headline |
| Four-point block | Same warm-ivory field-card treatment as ET-01's contact-details block | `#FAF8F4` background, `#E5DFD4` border, bronze-labeled numbered points |
| Card / page background | Not on dark site theme — chosen as light, email-safe equivalent | `#FFFFFF` card / `#FAF8F4` page |
| Headline font | `--serif` `'Instrument Serif'` (not email-safe) | Georgia serif fallback |
| Body font | `--sans` `'Inter'` (not email-safe) | Arial/Helvetica fallback |
| Footer | Given "-----" divider + tagline + confidentiality lines, rendered as a proper HTML footer bar instead of literal ASCII dashes | Bordered footer band, matches ET-01/ET-02's footer-bar pattern |

> First name token: the source copy said `{{First Name}}` — mapped to GHL's actual standard merge field `{{contact.first_name}}`.
>
> Sender name token: the source copy said `{{Growth Manager Name}}` — this isn't a contact field, so it's mapped to a GHL **Custom Value** (`Ritesh Watts`), set once in `Settings → Custom Values` rather than per-contact. See Outstanding below.
>
> The four qualification points are pulled into their own bordered block (rather than a plain numbered list) so they read as a distinct "fill this in" section the recipient can scan at a glance — consistent with how ET-01 sets contact details apart from the surrounding paragraph copy.
